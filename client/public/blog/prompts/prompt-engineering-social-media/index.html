Hooks first, always

  • "Write 15 opening lines for a post about [topic]. Mix: question, bold claim, statistic, story open, contrarian take."
  • "Rewrite this opening to create curiosity without being clickbait: [line]"
  • "Which of these hooks would stop a Bangladeshi user mid-scroll, and why? [list]"
