Prerequisites — be honest with yourself

The course explicitly states that enrolling without adequate Python knowledge leads to serious difficulty.

  • Python programming — required, not optional
  • Basic mathematics — linear algebra and probability help considerably
  • Machine learning basics — recommended, briefly reviewed in class
  • BUET also offers an Introduction to Python course as preparation
⚠️ Do not skip the Python prerequisite. The course involves hands-on model training and coding assignments. Without working Python, you will not be able to complete the work, and the responsibility is explicitly the participant's.

How to prepare using AI

Ironically, the best preparation for an AI course is using AI.

  1. "Build me a 6-week Python learning plan for someone with no programming experience."
  2. "Teach me NumPy and Pandas basics with exercises."
  3. "Explain linear algebra concepts used in machine learning, with examples."
  4. "Give me 10 Python exercises that build toward machine learning work."
  5. "Explain what a neural network does, mathematically and intuitively."

Who should take it

  • Good fit: CSE students and graduates, working developers, people with Python who want to build AI systems
  • Poor fit: complete beginners with no programming background — start with the Ministry of Youth basic course instead
  • Also consider: CUET's ITBI AI & ML course, which starts from a lower baseline
